# Frontend Odyssey: The Dev Cycle — A True Story

An interactive, scroll-based storytelling experience that captures the emotional and technical journey of a software developer.

## 🚀 Overview

This project is a single-page web application that uses high-fidelity animations and interactive elements to tell the story of "The Dev Cycle." From the initial spark of an idea to the depths of "Tutorial Hell," the frustration of a persistent bug, the "Grind," and finally the triumph of a working project.

## ✨ Features

- **Interactive Storytelling:** A narrative-driven experience controlled by scrolling.
- **GSAP Animations:** Smooth, performant animations powered by GreenSock and ScrollTrigger.
- **Dynamic Themes:** CSS variable-based theming that changes as you progress through the chapters.
- **Custom UI Elements:** 
  - Interactive terminal-themed loader.
  - Custom cursor system with magnetic/hover effects.
  - 3D tilt effects on cards.
  - Synthesized audio feedback (SFX).
- **Responsive Design:** Optimized for various screen sizes.

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Semantic structure and modern styling (Vanilla CSS).
- **JavaScript:** Core logic and interactivity.
- **GSAP (GreenSock):** Animation orchestration and scroll synchronization.
- **Google Fonts:** Space Mono, Bebas Neue, and Caveat.

## 🏁 Getting Started

Since this is a standalone HTML project, you can run it simply by opening `index.html` in any modern web browser.

```bash
# Clone the repository
git clone https://github.com/your-username/Frontend-Odyssey.git

# Open the project
# (Simply double-click index.html or use a live server extension)
```
